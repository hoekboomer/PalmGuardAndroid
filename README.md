# 掌拒（PalmGuard）

一个 Android 13+ 的接触面积防误触原型。它优先读取系统报告的触点椭圆长短轴；这些数据不可用时，再尝试工具大小轴，最后尝试系统提供的归一化 `size` 值。大面积触摸会被抑制，小面积触摸则交给当前应用。普通被识别成“手指”的电容笔也能按触点大小参与判断。

> **当前状态：尚未达到预期效果，仍需完善。** 目标使用方式是手缘先落并被屏蔽，随后落下的电容笔仍可正常连续书写，同时不会让前台应用把手缘和笔尖当成双指操作。当前版本尚未稳定实现这一效果；实机上仍可能出现多点触控或手势，不能视为问题已解决。

## APK 安装

安装包：[下载 PalmGuard-0.1.7-debug.apk](./PalmGuard-0.1.7-debug.apk)。将 APK 复制到手机并点开，按系统提示确认安装；如果系统阻止安装，在提示中允许当前文件管理器安装应用。安装后打开“掌拒”，进入系统辅助功能设置启用“掌拒：接触面积防误触”，再回到应用打开全局开关。

这是用于试用的 debug 签名 APK，适合手动安装和验证，不是面向商店发布的正式签名包。

## 使用

1. 用 Android Studio 打开此文件夹，使用 JDK 17 同步并运行 `app`。
2. 打开应用，在系统辅助功能设置中手动启用“掌拒：接触面积防误触”。
3. 在应用内打开“启用全局防误触”，用笔尖和手掌在校准区域试触，再调整面积阈值。

全局开关默认关闭。辅助功能服务只用于接管触摸判定；关闭全局开关或在系统辅助功能设置中关闭服务即可停止。

## 原型限制

- 需要 Android 13（API 33）或更高版本，因为全局触摸判定使用 `TouchInteractionController`。
- 应用依次回退到 `toolMajor/toolMinor` 和归一化 `size`。这些触摸指标由设备触屏驱动提供；如果它们全为 0，应用无法获取面积信息，会放行触摸以避免误拦正常操作。
- `size` 是 0–1 的粗略且非线性的系统值，因此有单独阈值；不同设备需要在校准区实测调整。
- 多点时当前实现尝试只把最后落下且仍按住的触点交给前台应用，但尚未证明能在目标设备上稳定实现“手缘先落被屏蔽、笔尖后落仍可连续书写”。实机仍可能把手缘和笔尖作为多个触点处理，导致双指手势或书写中断。
- 初始单点对可用的椭圆/工具面积短暂等待 80 毫秒；面积信息未知或只能读取到较弱的归一化 `size` 时继续等待，避免手缘先落后被提前放行。
- 触点轴数据受设备、屏幕和驱动影响；面积数据缺失或为 0 时当前实现无法可靠区分手缘与笔尖。默认阈值只是起点，仍需在目标设备上完善检测与触点筛选逻辑，并验证系统手势和多点触摸行为。
- 辅助功能服务会参与全屏触摸分发。此原型不是 Play 商店发布版，也没有覆盖不同厂商系统的兼容性验证。
